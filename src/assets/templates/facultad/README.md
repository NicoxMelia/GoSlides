# Logos de la plantilla de facultad

`logo_fcefyn.png` y `logo_unc.png` son los archivos originales proporcionados por
el usuario para la plantilla UNC / FCEFyN. Se copiaron sin modificar sus píxeles.

El logo FCEFyN conserva sus márgenes blancos en el archivo: el recuadro de imagen
del master utiliza el ajuste `cover` para mostrar la marca a un tamaño legible.
Ambos PNG se incluyen como assets locales al crear y exportar la presentación.
